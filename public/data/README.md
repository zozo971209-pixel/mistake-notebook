# Offline world base map

`world-countries-110m.geojson` is a lightweight country-boundary base map derived from Natural Earth 1:110m data via the `datasets/geo-boundaries-world-110m` package.

- Source: https://www.naturalearthdata.com/downloads/110m-cultural-vectors/110m-admin-0-countries/
- Package: https://github.com/datasets/geo-boundaries-world-110m
- Purpose: neutral offline geographic context only. It does not contain the user's climate, terrain, agriculture, historical, or other learning content.
- Boundary caveat: Natural Earth uses de facto boundaries; do not treat the base map as a source for disputed-boundary claims.
